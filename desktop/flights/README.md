# Axesta Spawn Flights

Helyezd ide az MSFS-ből exportált `.flt` fájlokat:

- `pmdg737.flt` — PMDG 737-800 ready state
- `fenix.flt` — Fenix A321 ready state  
- `a32nx.flt` — FlyByWire A32NX ready state

## Hogyan ments el state-et MSFS-ben:
1. Töltsd be a repülőt és állítsd be a cockpit state-et
2. MSFS menü → Load/Save → Save Flight
3. Másold a .flt fájlt ide
