# SkyBound EFB Desktop

## Firebase setup — Email/Password auth engedélyezése
Firebase Console → simapp-99f40 → Authentication → Sign-in method → Email/Password → Enable

## Első fiók létrehozása
Az app "Regisztráció" gombbal hoz létre fiókot — semmi extra teendő.

## Build
npm run dev       # fejlesztés
npm run dist:mac  # .dmg (csak macOS-en)
npm run dist:win  # .exe (csak Windowson)
